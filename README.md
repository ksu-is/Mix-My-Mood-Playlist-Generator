# Mix-My-Mood-Playlist-Generator
Mix My Mood Playlist Generator is a program designed to help users find music that matches their current emotions. By selecting a mood such as happy, sad, stressed, or relaxed, the system generates a playlist with songs that fit that feeling. 
## Purpose
The goal of this project is to make it easier for users to quickly find music that matches their mood without having to search for songs manually for long period of time.
## Features (Planned)
- Mood selection (happy, sad, stressed, relaxed)
- Playlist generation based on mood
- Easy and interactive user input
